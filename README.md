# PyQuest

Nền tảng học **Python thật** cho học sinh cấp 2: học cách làm ra một sản phẩm, từ bức tranh toàn cảnh tới game hoàn
chỉnh. Khóa đầu: **Bay Qua Khe**.

- Bắt đầu: `npm install && npm run dev` → http://localhost:5173
- Cho lớp dùng qua LAN: `PQ_HOST=1 tools/coach-dev.sh` (xem `docs/architecture/deployment-ops.md`)
- Agent và người mới: đọc `AGENTS.md` trước.

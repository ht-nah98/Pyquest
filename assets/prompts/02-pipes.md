# 02 · Chướng ngại vật (cột trên + cột dưới)

**Cỡ đích sau khi làm sạch:** cột rộng 52 px, cao 320 px. Code tự lật ngược cột để làm cột phía trên, nên chỉ cần sinh
**một cột đứng thẳng**, đầu cột ở **phía trên**. Thân cột phải **lặp được theo chiều dọc**, để code kéo dài hay cắt ngắn
mà không lộ vết nối.
**Tỉ lệ khi sinh:** 1:4 hoặc 9:16, cột đứng giữa ảnh.

Mỗi prompt = phần riêng + đoạn phong cách chung trong `README.md`.

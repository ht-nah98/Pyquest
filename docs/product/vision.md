# Tầm nhìn

PyQuest dạy học sinh cấp 2 **làm ra sản phẩm bằng Python**. Không dạy lý thuyết dài, không cắm đầu vào code: mỗi khóa
mở đầu bằng bức tranh toàn cảnh (sản phẩm có những phần nào, làm theo quy trình nào), rồi đi từng phần theo nhịp
Hiểu → Thiết kế → Chuẩn bị → Code → Chơi thử.

- Khóa 1 **Bay Qua Khe**: game luồn khe. Thành công = bé có game chơi được, do chính mình viết.
- Về sau: nhiều game Python khác, vẽ hình, phân tích dữ liệu. Thêm khóa = thêm thư mục trong `content/courses/`.
- Phần nâng cao (tự sửa luật, thêm tính năng, không hướng dẫn) để sau.

Chi tiết và lý do: `../superpowers/specs/2026-11-04-pyquest-design.md`.

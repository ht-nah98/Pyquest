# Giấy phép đi kèm trang web

Chép nguyên văn từ gói cài trong `node_modules`, không tự viết.

| Thứ đi kèm | Giấy phép | Tệp |
|---|---|---|
| Blockly (và `blockly-media/`) | Apache-2.0 | `blockly.txt` |
| pixelfx (hình `fx-*`) | MIT | `pixelfx.txt` |
| Pyodide (`pyodide/`) | MPL-2.0 (theo `package.json`) | chưa có: gói npm không kèm văn bản giấy phép |
| Phông VT323, Baloo 2, Nunito (`fonts/`) | OFL 1.1 (theo `src/ui/fonts.css`) | chưa có: tệp phông tải từ Google Fonts, không kèm văn bản |
